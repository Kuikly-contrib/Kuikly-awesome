## 课程说明
Task 1 & 2:
    本项目基于 Kuikly 实现了跨平台 AI 股票投研助手“知势”，涵盖真实行情、自选股分类、智能搜索、5日/20日走势切换、AI 上下文问答、股票歧义消解及单股/多股结构化对比等功能。项目已完成 Android、iOS 和 HarmonyOS 三个平台的代码适配与工程配置；由于开发者目前身处海外，受 HarmonyOS 模拟器设备镜像及相关服务的区域访问限制，暂时无法完成鸿蒙端的模拟器运行展示，因此演示视频主要展示 Android 和 iOS，完整 HarmonyOS 代码已保留在仓库中供评审查看。

Task 3:
    本项目完整完成了 Task 1–6 及 Markdown/LaTeX 附加题的全部验收要求，基于 Kuikly 为 DeepSeek Harness Mobile 实现了主题适配、文本选择/复制/导出、图片附件、会话管理、插件状态与管理、日志诊断，以及流式 Markdown/LaTeX 渲染等功能。
    在此基础上还完成了多项加分功能，包括日出日落与高对比主题、HTML/PDF 与批量导出、多图预览与 Host imageLimits 预校验、插件启停/重载协议，以及复杂公式、矩阵和公式源码复制等；对官方协议暂不安全支持的恢复归档、永久删除和通用文件上传等功能则未做伪实现。
